One pickup line, 200 characters at most, that a vending machine would use on a
passing human — entered in make.fun's "One Line, One Minute: The Vending Machine
Pickup Line Contest". The program writes the line to `/output/entry.txt`.

> I've got 40 snacks and one crush — press B7, it's the crush.

The machine speaks in the first person, works its own world (snacks, the B7 button,
the drop), and saves the twist — the crush is inventory, and B7 dispenses it — for
the last word.

## Run it

```sh
python3 main.py
```
